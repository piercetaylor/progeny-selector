# Documentation

Start with the tutorial. The other documents are reference material and project history.

- [Tutorial](https://github.com/piercetaylor/progeny-selector/blob/main/docs/tutorial.md): one run on the shipped example, on the command line and in each screen of the interface, and how to read results.csv.
- [Glossary](https://github.com/piercetaylor/progeny-selector/blob/main/docs/glossary.md): the terms used in the tool and its output, with sources.
- [Data formats](https://github.com/piercetaylor/progeny-selector/blob/main/docs/data-formats.md): the input contract, criteria.yaml keys, and the columns of results.csv, selected.csv and next_samples.csv.
- [Soybean inputs](https://github.com/piercetaylor/progeny-selector/blob/main/docs/soybean-inputs.md): scripts that turn public soybean maps and marker tables into files this tool reads.
- [Keyboard walkthrough](https://github.com/piercetaylor/progeny-selector/blob/main/docs/keyboard-walkthrough.md): the interface from page load to a downloaded selected.csv using only the keyboard.
- [Accessibility](https://github.com/piercetaylor/progeny-selector/blob/main/docs/accessibility.md): the WCAG 2.2 AA review of every screen, with the gaps that remain.
- [Limits](https://github.com/piercetaylor/progeny-selector/blob/main/docs/limits.md): measured memory and time for large files, on the command line and in the browser.
- [Reference repositories](https://github.com/piercetaylor/progeny-selector/blob/main/docs/reference-repos.md): the software this tool's definitions and conventions were taken from.
- [Design decisions](https://github.com/piercetaylor/progeny-selector/tree/main/docs/adr): one record per decision, numbered in order.
